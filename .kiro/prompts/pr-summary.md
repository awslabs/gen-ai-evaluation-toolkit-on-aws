# PR Summary Generator

Generate a concise pull request title and description for commits that have diverged from origin/dev.

## Instructions

1. Fetch latest origin/dev and identify commits to summarize
2. Analyze the overall purpose and impact of all changes
3. Create a clear, actionable PR title (max 60 characters)
4. Write a brief description (max 3-4 sentences) covering:
   - What was changed/added
   - Why the change was made
   - Any notable impacts

Ignore [TODO] because this is for the user to fill out. If you don't have the correct information you can put [TODO] for the human to fill out.

## Output Format

**Title:** [Clear, concise title]

**Ticket link:** [TODO]

**Testing (e2e, manual):** [TODO]

**Description:** 
[Brief paragraph describing the changes and their purpose]

Keep it simple and focused on the key changes that matter for reviewers.
